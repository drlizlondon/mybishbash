Add Instagram with myBishBash

This adds a Home Screen launcher for myBishBash. It is a shortcut you can use before opening Instagram; it does not install or replace the real app.

iPhone
  1. Open this page in Safari.
  2. Tap Share.
  3. Tap Add to Home Screen.
  4. Tap Add.
Android
  1. Open this page in Chrome.
  2. Tap the three dots.
  3. Tap Add to Home screen or Install app.
  4. Tap Add or Install.

If you cannot see Share, copy this link and open it in Safari.
